# 英作文ドリル

センテンスリピートドリルの英文を、日本語を見ながら**組み立てて**答える英作文アプリです。話さずに、タップと入力だけで練習できます。

公開先: https://moko-middo.github.io/eisakubun/

## 遊び方

- 日本語の文を見て、英文を組み立てる
- その日の**復習語彙**（✎ のカード。日本語のヒント付き）は、置くと入力欄になるので**英語を打ち込む**。活用（having / developed など）も自分で変える
- それ以外の語は**カードを並べ替え**
- 冠詞（a / an / the）は覚える対象にしないので、後ろの語とくっついたカードになる（入力する語の前の冠詞は入力欄の前に表示され、打たなくてよい）
- 「ヒント」で入力語の各単語の最初の文字と文字数を表示
- 答え合わせで、合っている位置は緑・違う位置は赤。綴りの間違い、模範解答（🔊 で読み上げ）、使った語彙を表示
- ドリルを日付ごとに選べる（最初は一番新しいドリル。新しいドリルが届くと自動でそちらから始まる）
- 答え合わせをした時点でその問題は解いたことになり、記録タブに移ったりページを開き直したりしても続きの問題から出る
- 「間違えた問題だけ復習する」で、最後に解いたとき不正解だった問題だけを出せる。正解すると復習リストから外れる

### 続けたくなる仕掛け

- **ホーム画面に追加**できる（Android の Chrome なら メニュー →「ホーム画面に追加」／「アプリをインストール」）。アイコンから全画面で開け、オフラインでも動く
- **🔥 連続日数**と**今日の目標**（何問解いたかのリング）。目標を達成すると紙吹雪。目標は記録タブで 5／10／20／30 問から選べる
- **コンボ**: 連続正解の数を表示し、自己ベストを更新するとお知らせ。正解すると振動＋効果音（コンボが続くほど音が高くなる。🔊 で消せる）
- **あゆみタブ**: 今の連続日数・最長連続・1日の最高記録・やった日数と、1日 1 マスのマイクラ風ブロックのカレンダー（解いた数で 空気 → 土 → 草（目標達成）→ 金（2倍）→ ダイヤ（3倍））。集めたブロックの数も表示
- **終わりのない出題**: 選んだドリルを解き終えると、間違えた問題 → まだ解いていない問題 → しばらく解いていない問題 の順に「おすすめ」が続く

記録はブラウザ内（localStorage）だけに保存されます。

## ドリルの追加

`content/drills/` に MD ファイルを置いて `main` に push すると、自動でサイトが更新されます。
ファイル名は日付（`2026-11-17.md`、同じ日に 2 つ目なら `2026-11-17_2.md`）。

```
本日の復習語彙

* booking reference（予約番号・予約照会番号）
* have someone round（人を家に招く（英））

1. Please quote your booking reference when you phone the helpline.
2. We're having the neighbours round for supper on Friday evening.

## 日本語訳

1. ヘルプラインにお電話の際は、予約番号をお伝えください。
2. 金曜の夜、近所の人たちを夕食に招きます。
```

- `* 語（日本語）` の行が復習語彙。英文の中のその語が入力式になる（`someone` / `something` / `~` などは別の語に置き換わってもよい。`stalling / stall` のように `/` で並べるとどれか 1 つ）
- `番号. 英文` が問題の英文
- 和訳は、**別のセクションに同じ番号で** `番号. 日本語` と書く（英文の**すぐ次の行**に書いてもよい）。和訳のない文は問題にならない
- そのほかの行（タイトル、見出し、音声のファイル名など）は無視
